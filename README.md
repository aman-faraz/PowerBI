
# Power BI Projects Repository

This repository contains Power BI dashboard projects focused on transforming raw data into meaningful business insights using interactive visualizations and analytics.

The projects demonstrate:
- Data visualization
- Dashboard creation
- Business intelligence reporting
- Data cleaning & transformation
- KPI analysis
- Interactive storytelling with Power BI

---

# Projects Included

## 1. Adidas Sales Analysis Dashboard

This project analyzes Adidas sales data to uncover insights related to sales performance, profit trends, product categories, and regional performance.

### Key Insights
- Total sales & profit analysis
- Region-wise sales performance
- Top-performing products
- Monthly sales trends
- Retailer performance analysis
- Product category comparison

### Dashboard Features
- Interactive filters & slicers
- KPI cards
- Sales trend charts
- Geographic analysis
- Dynamic visualizations

### Tools Used
- Power BI
- Power Query
- DAX
- Excel / CSV datasets

## 2. Ice Cream Sales Analysis Dashboard

### Key Insights

### Dashboard Features
- Interactive dashboard visuals
- Dynamic filtering
- Trend analysis
- Comparative charts
